Privacy Policy

Effective & last updated: September 5, 2026

Umberlull's publishing integration connects to social media platforms (including TikTok's Content Posting API) solely to upload Umberlull's own video content to Umberlull's own accounts. This policy explains what data that requires and how it's handled.

01 Overview

This is not a consumer-facing app. There are no end users or site visitors whose personal data is collected. The only accounts connected to this integration are Umberlull's own social media accounts, connected by Umberlull for the purpose of publishing Umberlull's own content.

02 Data we collect

DataWhy
OAuth access & refresh tokensIssued by each platform (TikTok, YouTube, Meta) when Umberlull authorizes the integration; used to authenticate future publish requests without repeated logins.
Account identifiersThe platform-assigned ID of the connected Umberlull account, used to target the correct account when publishing.
Post status metadataPublish IDs and processing status returned by the platform, used only to confirm an upload succeeded.

No data is collected from viewers, followers, or any account other than Umberlull's own.

03 How it's used

The data above is used exclusively to authenticate to Umberlull's connected accounts and publish Umberlull's finished video content, with its title, description, and caption. It is not used for advertising, analytics resale, profiling, or any purpose beyond operating the publishing pipeline itself.

04 Storage & security

Tokens are stored in a local environment configuration file on infrastructure Umberlull directly controls, and are not stored in any third-party database or analytics service.

05 Third-party sharing

Umberlull does not sell, rent, or share this data with any third party. It is used only for direct communication with the platform APIs (TikTok, YouTube, Meta) that issued it.

06 Retention & revocation

Tokens are retained for as long as the integration remains connected. Access can be revoked at any time from the relevant platform's own connected-apps settings (for example, TikTok's app permissions page), which immediately invalidates the token and stops any further use.

07 Changes to this policy

This policy may be updated as the integration or the platforms it connects to change. The effective date above reflects the most recent revision.
